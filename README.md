# violet-dev

Тема для Claude Code в приложении Claude (вкладка Code).

- Тёмная сине-бирюзовая палитра с тёплыми акцентами.
- Фон: спокойный градиент, по краям едва заметные фрагменты кода, панели под матовым стеклом.
- Сообщения в виде полупрозрачных скруглённых карточек.
- Строка лимитов над полем ввода: 5 часов, неделя и заполненность контекста. Команда `/limits` скрывает или показывает её.

## Установка

В приложении Claude, во вкладке Code: нажмите **+** рядом с полем ввода, затем **Plugins**, **Add marketplace** и введите `xMansory-dev/violetthemeclaude-dev`. После этого нажмите **Add plugin** и выберите `violet-dev`.

В сессии Claude Code в терминале:

```
/plugin install violet-dev --marketplace xMansory-dev/violetthemeclaude-dev
```

Из командной строки:

```
claude plugin install violet-dev --marketplace xMansory-dev/violetthemeclaude-dev
```

Репозиторий приватный, поэтому на компьютере должен быть настроен доступ к GitHub (например, вход через GitHub Desktop, SSH-ключ или `gh auth login`, затем `gh auth setup-git`).
